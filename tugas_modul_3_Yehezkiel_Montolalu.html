1. HTML Audio

Elemen <audio> digunakan untuk menyematkan suara ke halaman web. Atribut controls menyediakan tombol play, pause, dan volume.

Format audio HTML5 yang dibahas pada modul: MP3, WAV, dan OGG.

2. HTML Video

Elemen <video> digunakan untuk menampilkan video pada halaman web. Atribut controls memberikan kontrol pemutaran.

Format video HTML5 yang dibahas pada modul: MP4, WebM, dan OGG.

Pilihan video

3. YouTube Video

Klik thumbnail untuk membuka video dan playlist langsung di YouTube.

Tonton di YouTube

Video akan terbuka di tab baru agar dapat diputar tanpa kendala pemutar sematan.

4. HTML Geolocation API

Geolocation API digunakan untuk mendapatkan posisi geografis pengguna. Browser akan meminta izin pengguna sebelum lokasi dapat diakses.

Klik tombol untuk mendapatkan koordinat.

Data utama yang dikembalikan adalah latitude, longitude, dan accuracy. Data lain seperti altitude, heading, speed, dan timestamp dapat tersedia apabila didukung perangkat/browser.

5. HTML Drag and Drop API

Elemen dapat dibuat dapat diseret menggunakan atribut draggable="true". Event ondragstart, ondragover, dan ondrop digunakan untuk proses drag and drop.
